# 2026 年历螺旋 · 动态壁纸

一个真正安装在安卓手机上的动态壁纸（Live Wallpaper），用 Kotlin + WallpaperService 实现：
365 个点按黄金角螺旋排布，暗色是已经过去的天数，亮色是剩余的天数，"今天"那个点带一圈呼吸光环。
天数用 `Calendar.DAY_OF_YEAR` 实时读系统日期，装上以后每天自动更新，跨年也不用改代码。

## 办法一：用 GitHub Actions 免费云端编译 APK（不需要装任何软件）

1. 注册一个免费的 GitHub 账号（已有的话跳过）：https://github.com/join
2. 新建一个仓库（New repository），随便起个名字，设为 Public 或 Private 都行。
3. 把这个文件夹里的文件上传到仓库（"Add file → Upload files"，拖进去，点 "Commit changes"）。
   注意：GitHub 只认 `.github/workflows/` 这个隐藏路径里的流程文件，网页上传会跳过隐藏文件夹，
   所以流程文件在本包里放在可见的 `github-workflow/build-apk.yml`。上传完后再手动建一次：
   Add file → Create new file → 文件名框里直接输入 `.github/workflows/build-apk.yml`（输入 `/` 会自动建文件夹），
   把 `github-workflow/build-apk.yml` 的内容粘贴进去，Commit。（仓库里已经有这个文件的话不用重复做。）
4. 上传完成后，点仓库顶部的 **Actions** 标签页。
   GitHub 会自动开始跑一个叫 "Build APK" 的流程（因为 `.github/workflows/build-apk.yml` 已经在仓库里了）。
   第一次编译大概需要 3～6 分钟。
5. 编译成功（绿色对勾）后，点进这次运行记录，
   页面最下面 "Artifacts" 里有一个 `YearSpiralWallpaper-debug-apk`，点它下载一个 zip，
   解压后里面就是 `app-debug.apk`。
6. 把这个 APK 传到手机上（微信传文件 / 数据线 / 网盘都行），点开安装
   （如果提示"未知来源"，去设置里允许一下就行）。
7. 打开安装好的 App，点【设为动态壁纸】；
   或者手动去 设置 → 壁纸与样式 → 动态壁纸 → 选"2026 年历螺旋"。

## 办法二：自己电脑上用 Android Studio

1. 用 Android Studio（Meerkat 及以上版本即可）打开这个文件夹（File → Open）。
2. 等待 Gradle 同步完成（第一次需要联网下载依赖）。
3. 用数据线连接手机（打开"USB 调试"），点击 Run ▶ 把 App 装到手机上；
   或者 Build → Build Bundle(s) / APK(s) → Build APK(s)，把生成的 APK 传到手机上自行安装。
4. 打开手机上的"年历螺旋"App，点击【设为动态壁纸】按钮。

## 说明

- `SpiralWallpaperService.kt` 是核心：每天的天数用 `Calendar.DAY_OF_YEAR` 实时计算，
  换到下一年会自动按新一年的总天数重新排布，不需要改代码。
- 只有"今天"那个光环在做轻量重绘（约 22fps），其余 364 个点是静态的，比较省电。
- 颜色、字号都在 `SpiralWallpaperService.kt` 里，可以直接改十六进制颜色值调色。
- 办法一生成的是**未签名的 debug 版 APK**，可以正常安装和使用，只是不能直接上架应用商店
  （上架需要一个正式签名，如果以后有这个需求可以再告诉我）。

## 版本 2 的更新

- 壁纸自上而下：年份 → 黄金角螺旋 → 剩余天数（Fraunces 字体，与最初网页卡片同比例）→ 穿越的话 → 底部一行（月日 / 星期 / 时钟）。
- 今天的那颗小圆点会呼吸：光晕起伏、向外扩散涟漪、圆点本体吸气时变大变亮。
- 暗点 = 今天之前已过去的天数；今天 = 呼吸点；亮点 = 今天之后剩余的天数。
- 字体放在 `app/src/main/assets/fonts/`（Fraunces，OFL 开源协议）；缺失时自动退回系统衬线体。
- 想微调位置：改 `SpiralWallpaperService.kt` 顶部那几个以 `_BASELINE` / `_CENTER` / `RADIUS_` 开头的比例常量。
- 注意：手机锁屏自带的大时钟、日期天气、锁图标是系统画的，壁纸无法移动或遮住它们。

## 版本 3 的更新

- 剩余天数对应的亮点改成立体小圆球（径向渐变 + 高光 + 光晕）；已过去的天数仍是暗色平点。
- 今天的圆球：3.4 秒一个周期的呼吸（大小、光晕起伏，向外扩散涟漪）+ 不规则闪烁（四角星芒忽长忽短、球面高光忽亮忽暗）。
- 版面按新的锁屏截图重排：螺旋在系统日期行下面，剩余天数在螺旋下，穿越的话放在系统解锁图标下方，不被系统元素遮住。
- 穿越的话：「我是从 2027年 1月 1 日穿越回来的」。
- 底部「月日 星期 时钟」一行默认关闭（锁屏已有系统日期）。想打开，把 `SpiralWallpaperService.kt` 顶部的 `SHOW_DATE_LINE` 改成 `true`；不想要顶部年份，把 `SHOW_YEAR` 改成 `false`。

## 版本 4 的更新

- 穿越的年份有了定义：穿越回来的年份 = 当前年份 + `TRAVEL_YEAR_OFFSET`（默认 1，即多一年）。今年显示 2027，到 2027 年自动变成 2028，不用再改代码。想改成多两年，把 `SpiralWallpaperService.kt` 顶部的 `TRAVEL_YEAR_OFFSET` 改成 2。
- 今天那颗球：保留比其他球大、3.4 秒一次的呼吸、光晕起伏、向外扩散的涟漪；取消了闪烁和星芒。

## 版本 9 的更新：穿越的话改成字幕式滚动

- 最多同时显示三行；字幕每停一会，就平滑地向上滚一行（0.9 秒，缓入缓出）。
- 亮度由「离焦点行的距离」决定：焦点行亮度正常；上面一行边上移边变暗，直到消失；下面一行从看不见逐渐变亮，滚到焦点位置时恢复正常亮度。
- 节奏：前三句各停约 2.6 / 2.2 / 2.6 秒，最后一句「我会做出什么改变？」（琥珀色）停 4.2 秒，再留一拍空白后从头循环。想调快慢，改 `SpiralWallpaperService.kt` 顶部的 `QUOTE_HOLD`（每句停留秒数）和 `QUOTE_GLIDE`（滚动一行用时）。
- 每次亮屏，字幕都从第一句重新开始，解锁前总能从头读到尾。
- 前三行不再统一压暗（改由滚动时的明暗体现层级）。

## 版本 10 的更新：语录数据库 + 每次锁屏自动换一条

- 语录库在 `app/src/main/assets/quotes.json`（共 63 条：1 条原创穿越语 + 2 条自选 + 40 条中国诗词曲 + 20 条西方诗文/名言）。可读版见 `quotes.md`。
- 格式：`{"id": 数字, "lines": ["第一行", "第二行", ...], "by": "出处"}`。想加一条，在数组里照抄一段、改文字即可；`by` 留空就不显示出处。文字里的 `{Y}` 会自动换成「当前年份 + `TRAVEL_YEAR_OFFSET`」。每行建议不超过 16 个字。
- 每次**锁屏的瞬间**，壁纸从库里抽下一条，下次亮屏就是新的。抽法是「洗牌袋」：全库洗乱后一条条抽，抽完一整轮才会出现重复，中途重启手机也不会重来。
- 字幕滚动沿用 v9：最多三行，焦点行正常亮度，上行渐暗消失、下行渐亮。每行停留时间按字数自动算；正文最后一句是琥珀色，之后是灰紫色的出处，再空一拍进入下一轮。
- 西方部分只选了公有领域作者（古希腊罗马、莎士比亚、雪莱、叶芝、里尔克等），中文为意译，不是任何现成译本。

## 版本 11 的更新：多种配色方案

- 6 套配色：琥珀夜（默认）、月光蓝、翡翠、玫瑰、紫晶、朱砂，外加「每次锁屏随机换」。配色表在 `Palettes.kt`，想加一套就照抄一行、改十六进制颜色。
- 怎么选：打开 App「年历螺旋」，点一套配色，立即生效；也可以在系统的 设置 → 壁纸 → 动态壁纸 里选中本壁纸后点「设置」进入同一个页面。
- 「每次锁屏随机换」：锁屏的瞬间换成另一套（不会和当前相同），下次亮屏就是新的。选了固定配色，就一直用那一套。
- 配色会改变：背景、已过去的暗点、小球和高光、今天那颗球的光晕、文字的亮暗、正文最后一句的颜色。锁屏上系统画的时钟和天气图标，会自动取壁纸主色，通常也会跟着变。
- 原来的 `activity_main.xml` 布局已删除，设置页改为代码绘制。
